# 构建生产级 AI Agent

这是一套完全以实操为导向的系列课程。我们会从零开始，通过可以直接运行的命令、最小代码和真实工程案例，逐步理解 AI Agent 如何搭建、背后依赖哪些技术栈，以及怎样把一个能够演示的 Agent 设计成可以在生产环境中可靠运行的系统。

课程不会只停留在框架 API 的用法上，而是会继续向下追问：Agent 执行代码时如何隔离风险，怎样安全地连接外部服务，LLM、检索与工具调用分别解决什么问题，以及系统的权限、状态、可靠性和评估体系应该如何设计。

## 课程结构

- `fundamentals`：构建 AI Agent 需要理解的基础知识，包括 Linux 容器与沙箱、鉴权与 OAuth、LLM 基础、RAG 等。
- `system-design`：生产级 Agent 的系统设计，包括组件边界、运行时、状态与任务管理、可靠性、安全性和可观测性等。
- `evaluation`：Agent 的评估方法，包括能力评估、安全评估、回归测试以及线上效果监控等。
